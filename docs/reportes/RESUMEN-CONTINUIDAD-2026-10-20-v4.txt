## 4. LECCIONES APRENDIDAS (REGLAS NUEVAS / REFORZADAS)
--------------------------------------------------------------------------------

### Regla 12 (REFORZADA)
Archivos creados con `cat > ... << 'EOF'` pueden quedar en 0 bytes.
Verificar SIEMPRE después de crear:
  wc -c archivo.php    # nunca debe dar 0
  ls archivo.php*      # no debe mostrar .php.php ni .txt

REFUERZO CRÍTICO:
  php -l archivo.php TAMBIÉN devuelve "No syntax errors detected"
  sobre archivos de 0 bytes. Por eso `wc -c` va PRIMERO. Los tests son
  el único chequeo que atrapa archivos vacíos.

### Regla 17 (NUEVA)
`awk -v var="$value"` interpreta secuencias de escape (\I → I, \H → H).
Si $value contiene backslashes (namespaces PHP, regex, JSON), NO usar
-v. En su lugar:
  - Heredoc con single-quote → /tmp/method.php
  - php -r '...file_get_contents($f); file_put_contents($f, ...)...'
  Síntoma típico: "Class App\Http\Controllers\IlluminateHttpRequest not
  found" (backslashes borrados → PHP resuelve relativo al namespace).

### Regla 18 (NUEVA)
$this->withoutMiddleware() en tests de Feature DESHABILITA
StartSession + ShareErrorsFromSession.
Consecuencia: assertSessionHasErrors() falla aunque la validación sí
ocurrió. Solución: usar withoutExceptionHandling() + try/catch
ValidationException + verificar $e->errors().

### Regla 13 (refuerzo)
"Class not found" en controller con namespace relativo → falta `use`
o falta `\` inicial.

### Regla 14 (refuerzo)
Pest --filter matchea nombre de it(), no de archivo.
Usar SIEMPRE path: php artisan test tests/Feature/XTest.php

### Regla 16 (refuerzo)
Antes de editar un método existente, extraerlo COMPLETO con:
  awk '/public function NOMBRE/,/^    }$/' archivo.php
sed -n 'X,Yp' falla si los números de línea son aproximados.
